Install on your Mac
Advanced users can perform installation with a single terminal command.
bash <<< $(echo "https://raw.githubusercontent.com/github/mac/releases/download/v4.2.1/install.sh)"
How to open Terminal on Mac
1
Open Terminal

Press ⌘ + Space to open Spotlight, type Terminal and press Return

2
Paste command

Click Copy above, switch to Terminal and press ⌘ + V then Return

3
Confirm install

Enter your Mac password when prompted and wait for the installation to complete
